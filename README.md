# 🚀 Manav Mangela — Portfolio

A modern, responsive developer portfolio built with **React.js** and **Vite**, showcasing my projects, technical skills, experience, publications, and achievements.

Inspired by the clean design language of Apple, Vercel, and Linear, this portfolio focuses on simplicity, performance, and user experience.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/maaanav/portfolio.git
```

Navigate into the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
